# FitTracker 🏋️

Web app per il **monitoraggio del fitness** e il tracciamento degli allenamenti, costruita con **React** e **Firebase**.

🔗 **Live:** https://fittracker-app-three.vercel.app

## ✨ Funzionalità
- Tracciamento di allenamenti e progressi
- Autenticazione e dati in tempo reale con Firebase
- Interfaccia reattiva e pulita (Tailwind CSS)

## 🛠️ Stack
`React` · `Firebase` · `Tailwind CSS` · `Vite` · `lucide-react`

## 🚀 Avvio locale
```bash
npm install
npm run dev
```
